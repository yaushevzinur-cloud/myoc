# MyOS Web V0.9 — Planner

Эта сборка V0.9 пересобрана с эталонным рабочим `config.js`,
который пользователь отдельно загрузил и подтвердил как правильный.

Что добавлено в V0.9:
- перепланирование задачи на конкретную дату;
- перенос день → неделя → месяц;
- перенос неделя → месяц;
- блок «Просрочено»;
- перенос просроченной задачи на сегодня или другую дату;
- архив выполненных задач по выбранному году и месяцам;
- сохранение истории перепланирований в `plannedHistory`;
- одна карточка без создания копий;
- Cloud Sync сохранён.

`config.js` уже правильный. Заменять его вручную НЕ нужно.
