# MyOS Web V0.11.3 — Goals Button Fix

Исправлена причина, по которой кнопка «Создать цель» не нажималась:
в app.js одновременно находились две реализации goalCard()/bindGoals().
Поздняя bindGoals() искала кнопку createGoal, тогда как открытый экран goals()
рисовал кнопку goalAdd. Дублирующий блок удалён, оставлена одна согласованная
реализация целей.

Также тёмное оформление V0.11.2 применено к реально используемой форме.
config.js сохранён без изменений из присланной пользователем V0.11.2.
