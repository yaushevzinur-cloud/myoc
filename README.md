# MyOS Web V0.11.4 — Goals Navigation Fix

Исправлено открытие «Цели и приоритеты».

Причина: после очистки дублирующей логики в V0.11.3 на экране «Я»
осталась ссылка на удалённую функцию `goalsScreen()`. При нажатии на текст
кнопки браузер получал JavaScript-ошибку и экран целей не открывался.

Теперь вся кнопка «Цели и приоритеты» вызывает только `render("goals")`.

Логика создания целей из V0.11.3 сохранена.
`config.js` не изменён.
