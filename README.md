# MyOS Web V0.3 — Reading
Главное обновление: полноценный модуль чтения.
- Индивидуальная дневная норма по каждой книге.
- Казахский можно держать на 5 стр./день, остальные книги — например 10 стр./день.
- Текущая страница, общий объём и процент книги.
- Кнопки +1 / +5 / +10 страниц.
- Остаток на сегодня и ориентировочное число дней до конца книги.
- Добавление, редактирование и удаление книг.
- Данные сохраняются локально в браузере.
- Кэш service worker отключён на этапе разработки, чтобы обновления Vercel не застревали.
