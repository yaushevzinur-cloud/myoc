# MyOS Web V0.12.2 — Languages Safe Form

Пересобрано заново от пользовательской рабочей V0.12.0, где раздел «Языки» точно открывался.

Исправлено безопасным способом:
- навигация «Я → Языки» оставлена без изменений от рабочей V0.12.0;
- «+ Занятие» больше не использует prompt() и не создаёт глобальное модальное окно;
- форма занятия раскрывается прямо внутри карточки языка;
- поля: минуты + описание занятия + Сохранить/Отмена;
- «⚙ Норма» использует ту же встроенную форму;
- кнопки приведены к тёмному стилю;
- Goals ↔ Planner и config.js не изменены.
