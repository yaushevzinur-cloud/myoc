# MyOS V0.12.6 — Languages crash fix

Точная причина найдена:
- после первого сохранения занятия появляется `last` запись;
- карточка Languages пыталась вывести её через `esc(last.text)`;
- функции `esc()` в app.js вообще не было;
- поэтому после сохранения экран падал с ReferenceError и потом больше не открывался.

Исправлено:
- добавлена безопасная `esc()` для текста заметок;
- чтение `langToday()` больше не пересоздаёт `state.languages` во время рендера;
- уже сохранённая запись из Supabase/localStorage теперь должна нормально отображаться;
- прямой переход «Я → Языки» из V0.12.4 сохранён;
- Goals, Planner и config.js не изменялись.
