# MyOS V0.15.0 — Professional Knowledge Map

Основа: стабильная V0.14.

Первый шаг структуры обучения:
- у каждого профессионального направления появилась кнопка «🗂 Структура»;
- Нефтегаз: ГНКТ, КРП, Скважины и оборудование;
- внутри ГНКТ есть темы «Газлифт» и «Промывка / фрезерование»;
- «Газлифт» разбит на блоки: Теория, Оборудование / компоновка, Технология работ, Расчёты, Реальные кейсы;
- существующий элемент «ГНКТ газлифт» автоматически помещается в ГНКТ → Газлифт → Технология работ;
- из любого блока можно создать новый элемент, сразу привязанный к этому месту;
- подробная карточка V0.14 показывает путь в структуре знаний;
- Professional ↔ Planner, Languages, Goals и config.js не изменялись.
