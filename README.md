# MyOS Web V0.11.7 — Goals ↔ Planner Integration

Исправлено соединение целей с планировщиком:

- новые задачи из цели по-прежнему создаются во «Входящих»;
- старые связанные задачи без horizon автоматически переносятся во «Входящие»;
- в карточке цели вместо «Без периода» для таких задач теперь видно «📥 Входящие»;
- если у цели есть активные задачи во «Входящих», появляется кнопка «📥 Входящие»;
- эта кнопка сразу открывает «План → Входящие»;
- связь goalId, числовой прогресс цели и отдельный счётчик задач сохранены;
- config.js не изменён.
