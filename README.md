# MyOS V0.13.2 — Professional ↔ Planner

Основа: рабочая V0.13.1.

Добавлено:
- у каждого конкретного элемента Профразвития есть собственная кнопка «📥 В план»;
- создаётся одна связанная Planner-задача с `professionalItemId`;
- повторное добавление не создаёт дубликат;
- после связывания элемент показывает «🔗 В плане»;
- выполнение элемента в Профразвитии автоматически завершает связанную задачу Planner;
- повторное открытие элемента в Профразвитии возвращает Planner-задачу в активное состояние;
- выполнение задачи в Planner автоматически завершает тот же элемент Профразвития;
- перемещение задачи в Today Board в/из «Готово» также синхронизируется;
- восстановление задачи из архива синхронизирует элемент обратно в открытое состояние.

Languages V0.12.7, Goals и config.js не изменялись.
