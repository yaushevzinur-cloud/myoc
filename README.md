# MyOS V1
Первый интерактивный прототип персональной системы: экран «Сегодня», режим Вахта/Дом, AI-рекомендация, фокусы дня, временные кластеры, питание и привычки.

## Запуск
1. Установите Node.js LTS.
2. В папке проекта: `npm install`
3. Запустите: `npx expo start`
4. Для браузера нажмите `w`; для телефона используйте Expo Go и QR-код.
