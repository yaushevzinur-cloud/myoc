# MyOS Web V0.8.2 — Deliberate Date Planning

Исправлено планирование из месяца в неделю/день:

- кнопка из месяца больше НЕ отправляет задачу в текущую/случайную неделю;
- «📅 Выбрать дату» открывает календарь;
- выбранная дата автоматически определяет год, месяц и неделю;
- в недельной карточке запоминается конкретный день;
- «→ На 27 сентября» переводит задачу именно на выбранный день;
- «↻ Перенести» позволяет перепланировать ту же карточку без создания копии;
- история перепланирований сохраняется в `plannedHistory`;
- Cloud Sync V0.7/V0.8.1 логика не менялась.

ВАЖНО:
Перед загрузкой в GitHub скопируй РАБОЧИЙ `config.js` из локальной папки V0.8.1
поверх `config.js` этой V0.8.2. Это сохраняет твои публичные параметры Supabase.
Secret key и пароль базы не использовать.
