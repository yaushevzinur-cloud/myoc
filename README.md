# MyOS Web V0.10 — Analytics

Основа: стабильная V0.9 с подтверждённым рабочим `config.js`.

Новое в «Прогресс»:
- переключение аналитики: Неделя / Месяц / Год;
- процент выполнения запланированных задач;
- количество запланированных, выполненных и оставшихся задач;
- число карточек, которые перепланировались;
- разбивка по сферам: Работа / Здоровье / Развитие;
- динамика выполнения за последние 6 недель;
- текущий счётчик просроченных задач;
- фактически выполненные задачи за выбранный период;
- блок чтения сохранён.

V0.9 планировщик, архив, просрочки и Cloud Sync не менялись.
`config.js` уже правильный — вручную заменять его не нужно.
