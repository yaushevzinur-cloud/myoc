# MyOS Web V0.8 — Calendar Planning + Cloud Sync

Основа: рабочая V0.7 Cloud Sync.

Добавлено в V0.8:
- задачи привязаны к конкретному году, месяцу, неделе и дате;
- переключение периодов фильтрует карточки по выбранному периоду;
- экран «Сегодня» получил навигацию по конкретным датам;
- при движении Год → Месяц → Неделя → Сегодня карточка получает выбранный календарный период;
- облачная синхронизация Supabase из V0.7 сохранена;
- localStorage остаётся резервной локальной копией.

Важно: config.js содержит только publishable key. Secret key и пароль базы в клиентский проект не добавлять.
