# MyOS V0.13.1 — Professional Open Fix

Точная причина найдена:
- экран Professional использовал `root.innerHTML`;
- в MyOS контейнер называется `app`, а экраны рендерятся через `shell(...)`;
- переменной `root` в приложении нет, поэтому при открытии раздел падал с ReferenceError.

Исправлено:
- Professional теперь рендерится через `shell(...)`, как Languages и остальные экраны;
- добавлен `bindMode()` после рендера;
- остальная логика V0.13.0 не менялась;
- Languages V0.12.7 не затронут.
