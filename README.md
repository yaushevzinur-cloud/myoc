# MyOS Web V0.4 — Planning System
- Входящие → Год → Месяц → Неделя → Сегодня → Выполнено.
- Одна карточка проходит через горизонты планирования.
- Старые задачи V0.3.1 сохраняются и мигрируют в «Сегодня».
- На телефоне Kanban показывает одну стадию на экран.
- «Жду / мяч на их стороне» сохраняет, от кого или чего ждём.
- Выполненные задачи остаются в архиве.
- Книги и прогресс чтения сохраняются.
