# MyOS Web V0.12.0 — Languages

Новый рабочий модуль «Я → Языки».

Добавлено:
- отдельные карточки Казахский / Английский / Китайский;
- ежедневная норма в минутах;
- быстрые +5 / +10 минут;
- запись занятия: минуты + краткое описание;
- прогресс на сегодня и серия дней;
- изменение ежедневной нормы;
- кнопка «В план», создающая обычную задачу во «Входящих»;
- данные сохраняются в общем state и синхронизируются через существующий Cloud Sync.

Стабильная логика Goals ↔ Planner из V0.11.9 не изменялась.
config.js сохранён без изменений.
