# MyOS Web V0.7 — Cloud Sync Beta

Что добавлено:
- постоянное хранение состояния MyOS в отдельном проекте Supabase;
- localStorage остается локальной резервной копией;
- при запуске MyOS сравнивает локальную и облачную копии и использует более свежую;
- после изменений данные автоматически отправляются в Supabase;
- в шапке отображается статус: ☁ Синхр. / ☁ Сохранено / ☁ Локально / ☁ Ошибка синхр.;
- календарное исправление V0.6.1 включено.

Перед загрузкой в GitHub:
1. Открой config.js через Блокнот.
2. Вместо PASTE_SUPABASE_API_URL_HERE вставь значение SUPABASE_URL из своего myos-supabase.txt.
3. Вместо PASTE_SUPABASE_PUBLISHABLE_KEY_HERE вставь значение SUPABASE_KEY.
4. Сохрани config.js.
5. Никогда не вставляй сюда Secret key или пароль базы.

Важно:
Текущая схема годится для теста синхронизации. Перед хранением рабочих/чувствительных данных нужно добавить Supabase Auth и сделать RLS по auth.uid().
