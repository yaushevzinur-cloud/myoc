# MyOS Web V0.6 — Calendar Planning

Добавлено календарное планирование поверх V0.5:
- конкретный год;
- конкретный месяц;
- конкретная неделя (понедельник–воскресенье);
- конкретная дата для задач «Сегодня»;
- навигация назад/вперёд по периодам;
- сферы жизни и цветовая маркировка V0.5 сохранены;
- существующие задачи мигрируют в текущий период без очистки localStorage.

Следующие этапы: улучшение выбора конкретной даты/переноса карточек, аналитика по реальным периодам и модуль «Работа».
