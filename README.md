# MyOS Web V0.11 — Progress Insights

Основа: рабочая V0.10 Analytics с тем же подтверждённым `config.js`.

Новое:
- сравнение текущей недели/месяца/года с предыдущим периодом;
- разница процента выполнения в процентных пунктах;
- сравнение по сферам Работа / Здоровье / Развитие;
- автоматический MyOS Insight: где темп вырос/снизился, сильная сфера и сфера,
  которой стоит уделить больше внимания;
- учитываются текущие просрочки;
- вся аналитика V0.10, планировщик V0.9 и Cloud Sync сохранены.

`config.js` не менять.
