# MyOS Web V0.8.3 — Selected Date Labels

UX-патч дневного планирования:
- Сегодняшний день показывает «Сегодня».
- Любая другая выбранная дата показывает конкретную дату, например «27 сентября».
- Кнопка добавления меняется на «＋ Добавить на 27 сентября».
- Поле ввода тоже подстраивается под выбранную дату.
- Логика V0.8.2 и Cloud Sync не менялись.

Перед загрузкой в GitHub скопируй рабочий `config.js` из своей локальной V0.8.2
поверх `config.js` этой V0.8.3.
