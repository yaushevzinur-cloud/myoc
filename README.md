# MyOS V0.14.0 — Professional Detail

Основа: стабильная V0.13.2 Professional ↔ Planner.

Добавлено:
- по нажатию на профессиональный элемент открывается отдельная карточка;
- 4 блока: цель изучения, заметки/конспект, практика, результат;
- старое поле note автоматически используется как начальная цель изучения;
- отдельная кнопка статуса в списке, чтобы открытие карточки не переключало выполнение;
- внутри карточки можно сохранить данные, завершить/вернуть элемент и отправить его в Planner;
- существующая двусторонняя Professional ↔ Planner синхронизация не изменялась;
- Languages, Goals и config.js не изменялись.
